## [0.1.0] - 2026-08-31

### Added

- "Dark command deck" theme: dark by default, with a matching light palette
- Collapsible sidebar as an icon rail, avoiding the macOS traffic lights
- Three font-size steps (small / normal / large), scaling controls and text together
- New "Grid Green" accent color
- "Changelog" and "About" pages in settings (Markdown-driven)

### Fixed

- macOS title hidden behind the traffic lights
- Wasted space caused by centering tool content
- Misplaced toasts caused by missing notification styles
- Oversized button text that was not the same height as inputs
